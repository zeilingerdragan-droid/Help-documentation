# 充值与 API Key 管理

在 PuLu AI 控制台中充值后，账号会通过余额按量付费。调用模型时，系统会根据模型价格从余额中扣费。

## 充值

1. 进入 PuLu AI 控制台。
2. 点击左侧面板的 **钱包**。
3. 在额度充值区域选择需要充值的金额并完成支付。
4. 充值成功后，即可通过已配置的 API Key 按量调用可用模型。

![钱包充值示例](/assets/image1.png)

::: tip
如果你刚完成充值但客户端仍提示余额不足，先刷新控制台页面，再重新发起一次最小测试请求。
:::

## 创建 API Key

1. 进入 PuLu AI 控制台。
2. 点击左侧面板的 **API 管理**。
3. 点击右上角 **创建 API 密钥**。
4. 创建后复制密钥，并保存到你自己的安全位置。

![API 管理入口](/assets/image2.png)

创建密钥时注意：

- 看清分组倍率，避免选择错误分组。
- 新手一般保持默认配置，不建议一开始开启过多限制。
- API Key 只展示一次，关闭页面前请确认已经保存。

## Key 权限说明

API Key 可以单独设置权限，常见控制项包括：

- **可用模型限制**：只允许该 Key 调用指定模型。
- **IP 白名单**：限制可使用该 Key 的来源 IP，降低泄漏后的风险。

::: warning API Key 是账户资产的钥匙
请不要把 API Key 发到聊天记录、公开仓库、截图或网页中。如确认泄漏，请尽快删除旧 Key 并重新创建。
:::
